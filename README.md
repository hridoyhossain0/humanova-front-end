# Humanova — Community & Volunteer Platform

A modern community-driven web application designed to connect people with meaningful local initiatives and upcoming community events. Humanova helps users discover opportunities to make a positive impact, join events, participate in community activities, and create initiatives that bring people together.

## 🛠️ Technologies Used

- **Next.js:** React framework used for high-performance rendering, routing, and building the full-stack application.
- **TypeScript:** Static typing for safer, more maintainable, and reliable development.
- **MongoDB:** NoSQL database used to store users, events, initiatives, and community-related information.
- **Better Auth:** Authentication solution used for secure user registration, login, session management, and authentication.
- **Tailwind CSS:** Utility-first CSS framework used to build the responsive and modern interface.
- **React:** Component-based library used to create reusable and interactive UI components.
- **Lucide React:** Icon library used throughout the application for clean and consistent interface icons.
- **JWT:**  Used for secure token-based authentication and authorization.
- **shadcn/ui:** Reusable and accessible UI components used to create a clean and consistent interface.
- **Sonner:** Toast notification library used to provide user-friendly success, error, and status notifications.

## 📱 Features

- **Community Event Discovery:** Browse upcoming community events and discover meaningful opportunities to participate locally.
- **Join Community Events:** Authenticated users can join events and keep track of the activities they are participating in.
- **Create an Initiative:** Users can create and share their own community initiatives to encourage others to participate.
- **Secure User Authentication:** Better Auth provides secure authentication and session management.
- **User Profile Management:** Users can manage their account information and access their community participation data.
- **Joined Events Tracking:** Users can view events they have joined and easily keep track of their community activities.
- **Community-Focused Categories:** Initiatives can focus on clothing drives, food support, green initiatives, community care, and other social activities.
- **Responsive Design:** Fully responsive interface designed for desktop, tablet, and mobile devices.
- **Modern Landing Page:** A visually engaging homepage communicates the platform's mission and encourages users to get involved.
- **Interactive Event Experience:** Users can discover event details and take meaningful actions directly from the platform.
